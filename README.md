# HAII Library

A curated library of resources on Human-AI Interaction, behavioral psychology, and decision-making.

**Where Psychology meets Technology**

## How to add resources

1. Open `resources.json`
2. Add a new object to the array:

```json
{
  "id": 4,
  "title": "Your resource title",
  "url": "https://link-to-resource.com",
  "category": "Research|Article|Book|Video|Paper|Tool",
  "description": "Brief summary of what this is about",
  "notes": "Your personal notes and key takeaways",
  "dateAdded": "2026-09-25",
  "datePublished": "2024"
}
```

3. Save
4. Commit and push to GitHub
5. It auto-deploys to Vercel

## Deployment

Deploy to Vercel:
1. Push to GitHub
2. Go to vercel.com
3. Import your `haii-library` repo
4. It deploys automatically
5. Your site is live!
